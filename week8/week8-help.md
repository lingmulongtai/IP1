# Week8 コード説明（IP1x08）

8-1.py

while loopを使って、indexを0から順番に増やしながら表示しています。
print_eachは0からn-1までの数字を表示します。
print_each1は文字列などのsequence全体を、indexを使って1つずつ表示します。
print_each2は指定されたindex nから最後まで表示します。
print_each3はn=0というdefault parameterを使っていて、nを省略した場合は最初から全部表示します。

8-2.py

find_letterはwhile loopで文字列を先頭から調べ、探している文字が見つかったらそのindexを返します。見つからなければNoneを返します。
find_letter1は同じ処理をfor loopで書き直したものです。
count_letterは1文字の出現回数を数えます。
count_lettersはnested loopを使って、複数の文字の出現回数を合計しています。

8-3.py

palindromeは、前から見た文字と後ろから見た文字を比較しています。
1つでも違う文字があればFalseを返し、最後まで違いがなければTrueを返します。
palindrome1はs[::-1]で文字列を逆順にして、元の文字列と同じかを1行で判定しています。

8-4.py

rotateは、文字列の各文字を1文字ずつ見て、アルファベットなら指定された数だけずらします。
小文字はaを基準に、大文字はAを基準にして、ordで文字を数値に変換しています。
% 26を使うことで、zを超えたらaに戻るようにしています。
最後にchrで数値を文字に戻しています。
数字、空白、句読点など、アルファベット以外の文字はそのまま残します。

ROT13の13が特別なのは、アルファベット26文字の半分だからです。13文字ずらす処理をもう一度行うと、元の文字に戻ります。
