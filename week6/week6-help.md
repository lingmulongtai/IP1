# Week6 コード説明（IP1x06）

各 `.py` は課題 PDF の節に対応しています。`6-3.py` / `6-4.py` は実行すると turtle のウィンドウが開きます。

## `6-1.py` 条件分岐（4点）

### 1.1 偶数・奇数・割り切り

- **`isDivisibleBy(n, m)`**: `n % m == 0` なら `True`（`m` で割り切れる）。
- **`evenOdd(n)`**: `isDivisibleBy(n, 2)` で偶数なら `"even"`、そうでなければ `"odd"` を**返す**（`print` しない）。
- **Part 1**: `for i in range(10)` で 0〜9 を表示。
- **Part 3**: 0〜100 のうち 7 の倍数だけ `print`（0, 7, 14, …）。

### 1.2 年齢グループ

- **`ageGroup(age)`**: `if` / `elif` で表の区分（baby / school / student / employed / retired）を返す。
- 0〜69 をループして確認。

## `6-2.py` 再帰関数（3点）

- **`factorial(n)`**: `n < 1` なら `1`、else `n * factorial(n-1)`。
- **`sumOfCount(n)`**: 1〜n の和。`n <= 0` で `0`、else `n + sumOfCount(n-1)`。0〜9 → 0, 1, 3, 6, 10, …, 45。
- **`fibonacci(n)`**: PDF どおり `n <= 2` で `1`、else前二項の和（1番目の 1 はシーケンスの最初の 1）。
- **`gcd(a, b)`**: ユークリッド互除法。`b == 0` なら `a`、else `gcd(b, a % b)`。例: `gcd(24, 42) == 6`。

## `6-3.py` コッホ曲線（2点）

- **`koch(x)`**: `x < 3` なら直線 `forward(x)` で終了（`return`）。
- else、長さ `x/3` のコッホを4本、間に左60°・右120°・左60°。
- `koch(729)` で確認（729 は 3 の累乗なのできれいに分割できる）。

## `6-4.py` 雪の結晶（1点）

- **`snowflake(length)`**: 同じ長さのコッホ曲線を3辺分描き、毎回 `right(120)` で正三角形の雪片にする。
- `koch` はこのファイル内に同じ定義（単体で実行できるように）。

## チャレンジ `6-5-*.py`（ボーナス1点）

`printNum` を段階的に作る課題です。

| ファイル | 内容 |
|---------|------|
| **6-5-1.py** | 一の位を `print`、残り `n // 10` を `print`（3210 → 0 と 321） |
| **6-5-2.py** | 一の位のあと再帰 → **逆順**（0,1,2,3） |
| **6-5-3.py** | 先に再帰、最後に一の位 → **正順**（3,2,1,0） |
| **6-5-4.py** | `print(..., end="")` で1行に |
| **6-5-5.py** | 引数 `b` で基数変換（10→3210, 8→377, 2→101010） |
| **6-5-6.py** | 幅 `w` で先頭ゼロ埋め（例: 255,8,4 → 0377） |
| **6-5-7.py** | 埋め文字 `p`（`.` や空白） |
| **6-5-8.py** | デフォルト `b=10`, `w=1`, `p=" "` |

幅 `w == 0` のときは埋めずに全部の桁だけ出す（3210 の例）。
