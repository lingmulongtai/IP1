# Week5 コード説明（IP1x05）

各 `.py` は授業で作った `circle` / `arc` を前提に、課題の関数を実装しています。実行するとウィンドウが開き図が描かれます（`turtle.done()` で終了待ち）。

## `5-1.py` 正方形と四隅の円

- **目的**: 一辺 `length` の正方形の各頂点で、外側に半径 `radius` の円が接するように描く。
- **`circle(radius)`**: `turtle.circle(radius)` のラッパー（授業と同じ名前で使えるようにする）。
- **`squareCircles(length, radius)`**: 辺を描いたあと頂点にいるので、その位置・向きのまま `circle` を呼ぶと、亀の左側（正方形の外側）に円が描かれる。これを辺の数だけ繰り返し、角で `left(90)` して正方形を一周する。

## `5-2.py` 花びらと花

- **`arc(radius, angle)`**: `turtle.circle(radius, angle)` で、角度 `angle` 分だけ円弧を描く（全体円ではなく弧）。
- **`petal(radius, angle)`**: 同じ半径の弧を二つ、`left(180 - angle)` で挟んでレンズ形の花びらにする。対称なので、描き終わりの位置と向きは開始時と同じになり、同じ場所に重ね描きできる。
- **`flower(radius, angle, npetals)`**: `petal` を `npetals` 回描き、毎回 `left(360 / npetals)` して全体で一周の花にする。

## `5-3.py` 二等辺三角形とピザ

- **`triangle(length, angle)`**: 二つの等辺の長さが `length`、その間の角が `angle`（度）の二等辺三角形。底辺の半分は `length * sin(angle/2)`（`sin` には `math.radians` でラジアンに変換した角を使う）。亀を頂点に置き、最初に `left(90 - angle/2)` してから一辺・底辺・もう一辺を描き、最後に `right(90 - angle/2)` で向きを元に戻す。
- **`pizza(length, number)`**: 中心角がそれぞれ `360/number` 度のスライスが `number` 枚並ぶ円形。各スライスは `triangle(length, 360/number)` で描き、スライスごとに `left(360/number)` して次の位置へ回す。

## `5-4-1.py`（ボーナス）正方形を三角形の組み合わせで表す

- **目的**: 一辺の長さを引数にした関数で、Week1 で口頭練習した「正方形を三角形に分ける」パターンを Python で正確に指定する。
- **`pattern_square(side)`**: 正方形の中心を各二等辺三角形の**頂点**にし、頂角 90°、等辺の長さ `side * sqrt(2) / 2`（中心から角までの距離）として `triangle` を四回、`left(90)` ずつ回して四隅を順に覆う。底辺は正方形の辺と一致する（幾何で確認できる）。

## `5-4-2.py`（ボーナス）`goto` で正弦波

- **`sine_wave_two_cycles()`**: `x` を `-200` から `200` まで線形に変化させ、同じパラメータ比で位相 `angle` を `-2π` から `2π` へ対応させる。`y = 100 * sin(angle)` を `goto(x, y)` で結ぶ。最初は `up()` で飛ばし、描画開始後に `down()`（課題ヒントどおり）。

## `5-4-3.py`（ボーナス）任意関数とフーリエ部分和

- **`plot_function(f, ...)`**: `4.2` と同じく `x` と `angle` を対応させ、`y` に `f(angle)` をスケールして載せる。複数の曲線を縦にずらして（`y_shift`）同時に表示できる。
- **`f_sum_odd_harmonics(angle, max_k)`**: `k = 1, 3, 5, …, max_k` に対して `sin(k*angle)/k` を足し合わせるループ。`max_k=99` で課題の級数と一致する。
- **課題の最後の質問（要点）**: 奇数次の正弦だけを足していくと、波形はだんだん「角の立った」矩形波（デジタルの 0/1 に近い信号）に近づく。これは**フーリエ級数**で、任意の周期波形を正弦波の重ね合わせで表せることの例。通信・計測・DAC では、帯域を切ると角が丸まりギブス現象や折り返しが起きる、といった話につながる（レポートでは自分の言葉で因果を書く）。
