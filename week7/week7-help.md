# Week7 コード説明（IP1x07）

各 `.py` は課題 PDF の節に対応しています。`7-3-*.py` は対話入力なので実行すると `n:` のプロンプトが出ます。

## `7-1.py` ラッパー関数（1点）

- **`sind` / `cosd` / `tand`**: 度を `math.radians` でラジアンに直してから `math.sin` などを呼ぶ薄いラッパー。
- 検証: `sind(0)=0`, `sind(270)=-1`, `cosd(60)=0.5`, `tand(45)=1`。

## `7-2-*.py` 再帰とデバッグ（3点）

| ファイル | 内容 |
|---------|------|
| **7-2-1.py** | 呼び出しごとに `factorial n`、各 `return` の直前に `returning result`。`factorial(5)` で再帰の深さが見える。 |
| **7-2-2.py** | `isinstance(n, int)` と `n < 0` を毎回チェック。ダメならメッセージを出して `None`。 |
| **7-2-3.py** | チェックは外側の `factorial` だけ。計算は `_factorial` が再帰（`_factorial` 同士を呼ぶ）。 |

基底ケースは PDF どおり `n == 0` で `1` を返す。

## `7-3-*.py` センチネル値（2点）

| ファイル | 内容 |
|---------|------|
| **7-3-1.py** | 入力が `"stop"` ならループ終了。それ以外は `int` にして 2 倍を表示。 |
| **7-3-2.py** | ループ外に `total` と `count`。各整数で合計・個数を更新し、2 倍・合計・平均を表示。1〜5 なら total=15, average=3。 |

## `7-4.py` ニュートン法（4点）

- **`newton(n, epsilon)`**: 初期値 `s = n/2`。`|s*s - n| < n * epsilon` になるまで `s = (s + n/s) / 2`（相対誤差、4.4）。
- `__main__` で 4.1（`n=100` の素朴な版）、4.2〜4.4 のテスト出力あり。
- `n=2` では浮動小数点の完全一致ループが止まらないので、`abs` としきい値が必要（4.2）。

## `7-5.py` チャレンジ（ボーナス）

- `for n in range(1, 10)` で表を作成。
- **`pad(s, width)`**: 文字列化して幅までスペースで右詰め（列揃え）。
- `epsilon = 1e-7` 程度で `newton` と `math.sqrt` の差を比較。
