# Week11 コード説明（IP1x11）

各 `.py` ファイルは単独で実行できます。`text2.txt` を使う課題は、スクリプトと同じ `week11` フォルダのファイルを自動的に読み込みます。

## 11-1-1.py - 11-1-4.py

- `histogram(seq)` は、辞書のキーに要素、値に出現回数を保存します。
- `printAscending(d)` は `sorted(d)` を使い、キー順にキーと値を表示します。
- `printHistogram(d)` は、値の数だけ `*` を繰り返して棒グラフを表示します。
- 1.4では `d.get(item, 0) + 1` により、未登録のキーを0として一行で数えます。

## 11-2-1.py - 11-2-3.py

- `e2j` は英語の one - five を日本語の読みへ対応付けます。
- 2.2の `reverseMap(d)` は、元の値を新しいキー、元のキーを新しい値にします。
- 2.3では逆引き辞書の値をリストにし、同じ出現回数を持つ文字をすべて残します。たとえば3回出現する文字は `3 ['i', 'c', 'k']` になります。

## 11-3-1.py

`memo` に一度求めたフィボナッチ数を保存します。同じ引数の再計算を避けられるため、通常の再帰版より大幅に高速になります。実行すると両方の時間、速度比、結果が同じかを表示します。

## 11-4-1.py - 11-4-3.py

- `isLetter(c)` は、文字がアルファベットまたは空白なら `True` を返します。
- `depunctuate(word)` は `filter()` と `join()` で句読点などを除去します。
- 4.3は小文字に直した単語を辞書で数え、キー順に表示します。`do` と `know` はどちらも7回です。

## 11-5.py（ボーナス）

各行について、行数を1増やし、`split()` の長さを単語数へ、行の長さを文字数へ加えます。結果は41行、422語、2480文字です。
